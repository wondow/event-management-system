# Event Management System 🎉

This is a simple **Event Management System** built with **HTML, CSS, PHP, and MySQL**. It allows users to register, log in, and manage events from a user dashboard.

---

## 🚀 Features

- User registration and login
- Role-based dashboards (User/Admin)
- Event creation and management
- Password reset functionality (OTP planned)
- Clean, responsive UI using Tailwind CSS
